ANDROID INSTALL
Do not open/install the ZIP or local index.html directly. First host the extracted app over HTTPS.
1. Extract this ZIP.
2. In Chrome, open https://app.netlify.com/drop.
3. Upload the extracted folder (the folder containing index.html, manifest.webmanifest, sw.js and icon PNGs). If needed, upload all files inside it.
4. Open the published https://...netlify.app URL in Chrome.
5. Reload the page, tap ⋮, then choose Install app. If unavailable, choose Add to Home screen.
Entries are stored locally in this browser/device. Export backups regularly.
